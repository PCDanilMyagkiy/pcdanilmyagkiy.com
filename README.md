# pcdanilmyagkiy.com - Personal portfolio project built with the MERN stack and more



## Tech Stack


### Frontend

- React
- Vite
- Sass
- GSAP
- Lenis


### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- CORS
- cookie-parser
- JSON Web Token
- bcrypt
- Zod
- Nodemailer



## Features

- Authentication
- Email verification
- JWT-based authentication
- Calculator history
- Account management (changing name, email and password)
- Per-email rate limiting
- IP-based rate limiting
- Manual IP banning
